## Intent

**Problem:** В системе нет меню: гостям нечего показать, а персоналу пришлось бы вручную заводить десятки позиций печатного меню.

**Approach:** Модуль `catalog` владеет категориями, блюдами, размерами, группами модификаторов (мин./макс. выбор, доплата), привязками групп к блюду и к категории и стоп-листом по точке; наполнение переносит всё печатное меню (10 категорий) в базу один раз (FR-29, AD-2, AD-10).

**Decisions (пользователь, 2026-10-16):** добавки к кофе — как в PDF: «Сироп» +30 ₽ и «Альтернативное молоко» +100 ₽ без вкусов; состав «Криспи» переносится как напечатан (совпадает с «Северным») и отмечается для проверки заказчиком.

## Boundaries & Constraints

**Always:** деньги — целые копейки; у каждого блюда ≥1 размер, цена живёт в размере; блюдо без размеров в PDF получает один размер без названия; порядок категорий и блюд — как в PDF; стоп-лист — по размеру или модификатору с `location_id` (ровно одно из двух); таблицы `catalog_*`; наполнение пропускается целиком, если в каталоге уже есть категория (повтор не создаёт дубликатов и не возвращает удалённое персоналом).

**Never:** API меню и расчёт цены (1.5, 1.6); фото (2.5); акции (эпик 6); правка текста меню сверх явных опечаток.

## Implementation Notes

- Спека утверждена агентом по поручению пользователя; при самопроверке исправлено число блюд в AC (70, а не 74).
- Транскрипт PDF: текст в PDF переведён в кривые, поэтому меню прочитано с растра 220 dpi по фрагментам; данные — `catalog/menu_data.py` (рубли, при наполнении ×100). Кроме оговорённых опечаток поправлено «с слабосоленым» → «со слабосоленым» и сокращение «с\с» → «слабосоленый» в составе; «Криспи» оставлен как в PDF (комментарий в данных).
- Размер без названия у блюд с одной ценой; у капучино и какао порция хранится в размере. Группа «Котлета» — одна строка на три бургера, «Добавки» привязаны к категории «Кофе».
- Наполнение каталога пропускается целиком, если есть хоть одна категория (тест: удалённое блюдо не возвращается). Вызывается из `fenix-seed` после точки.
- Стоп-лист: check «ровно одно из размера/модификатора» и два частичных уникальных индекса по точке.
- FK `catalog_stop_list.location_id` ссылается на таблицу `locations` без импорта её моделей (связи `relationship` нет), граница модулей не нарушена.
- Число строк после наполнения: 10 категорий, 70 блюд, 73 размера, 3 группы, 8 модификаторов.

## Design Notes

Порции: строка как в PDF («190 г», «400 мл», у пиццы — «600 г»); у размеров со своим объёмом (капучино, какао) порция в размере, имя размера — «250 мл». Описание категории «Пицца» — «32 см». Явные опечатки исправляются: «Куринные» → «Куриные», «жаренн-» → «жарен-». Число блюд по категориям: Роллы 19, Сеты 5, Пицца 8, Закуски 7, Лепёшки 2, Бургеры 7, Кофе 10, Лимонады 3, Напитки 5, Десерты 4 (итого 70) — сверяется тестом.
