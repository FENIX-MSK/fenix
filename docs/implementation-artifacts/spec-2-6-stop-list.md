## Intent

**Problem:** Закончившиеся позиции продолжают продаваться: отметить их недоступными может только программист.

**Approach:** Вкладка «Стоп-лист» в разделе персонала: поиск и переключатели по размерам блюд и модификаторам точки; выключение сразу делает позицию недоступной у гостей, включение — возвращает (FR-28).

## Boundaries & Constraints

**Always:** записи стоп-листа — по `location_id` точки сотрудника; переключение идемпотентно (повторное выключение не создаёт дубль); блюдо, у которого выключены все размеры, у гостей «Закончилось»; скрытые позиции тоже видны в стоп-листе (с пометкой).

**Never:** стоп-лист по блюду целиком отдельной сущностью (только через его размеры); удаление позиций.

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|--------------|---------------------------|----------------|
| Выключить размер | `PUT /staff/stop-list {size_id, stopped:true}` | у гостя размер недоступен, цена «от» по оставшимся | — |
| Все размеры | выключены оба размера фри | у гостя «Закончилось» | — |
| Выключить модификатор | `{modifier_id, stopped:true}` | опция неактивна, расчёт с ней — 422 `unavailable` | — |
| Включить | `stopped:false` | позиция снова в продаже | — |
| Повтор | два выключения подряд | одна запись | — |
| Обе цели / ни одной | `size_id` и `modifier_id` вместе или пусто | 422 `bad_target` | единый формат |
| Неизвестный id | несуществующий размер | 404 `size_not_found` / `modifier_not_found` | единый формат |

## Implementation Notes

- Выключение — `INSERT … ON CONFLICT DO NOTHING` по частичным уникальным индексам (1.4), включение — `DELETE`; оба идемпотентны.
- Стоп-лист показывает и скрытые позиции (с пометкой), чтобы после возврата в меню их состояние было верным.
- UI: поиск по блюду, размеру, категории, модификатору и группе; переключатель «в наличии» (вкл = продаётся), зачёркнутое название и «закончилось»; оптимистичное переключение с откатом и «Не сохранилось…».
