# Дополнение к PRD — технические решения и контекст

Материал для архитектуры и реализации. В PRD не входит, потому что описывает «как», а не «что».

## Стек (зафиксирован в docs/decisions.md, этап 0 реализован)

- Бэкенд: Python 3.14, FastAPI, aiogram 3, SQLAlchemy 2 (async), Alembic, PostgreSQL 17, Redis, taskiq-воркер; uv, ruff, mypy --strict, pytest.
- Mini App: React + TypeScript + Vite; слой `src/platform/` поверх `@telegram-apps/sdk` — точка подключения MAX.
- Инфраструктура: VPS в РФ (Ubuntu 22.04, 2 vCPU / 4 GB), Docker Compose, Caddy (HTTPS, статика Mini App), Prometheus + Loki + Alloy + Grafana.
- CI/CD: GitHub Actions; `develop` — интеграция, `release` — деплой на VPS; образы в GHCR.

## Решения, принятые по ходу этапа 0

- **Канал к Telegram.** IP Telegram недоступны с VPS. Сервис `tg-egress`: туннель AmneziaWG (VPN-сервер в Амстердаме) только для подсетей Telegram + SOCKS5 во внутренней сети Docker; бэкенд ходит через `TELEGRAM_PROXY_URL`. Конфиг туннеля — только на сервере.
- **Бот — polling, не webhook.** Входящие соединения от Telegram на VPS ненадёжны; бот — отдельный сервис, API webhook не регистрирует.
- **Хранилище фото — Garage** (S3 API, AGPLv3) вместо MinIO: MinIO перестал публиковать образы. Работа через стандартный S3 API, чтобы можно было перейти на облачный S3 (Selectel, Yandex).
- **Python 3.14** вместо 3.13 (3.13 не скачивался из-за сети).

## Рекомендации для архитектуры

- Ядро (меню, корзина, заказы, оплата) не зависит от мессенджера; бот и Mini App — адаптеры.
- Transactional outbox для уведомлений (NFR-2): событие пишется в одной транзакции с изменением заказа, воркер доставляет с повторами.
- Идемпотентность платежей по ключу (FR-13); интерфейс провайдера оплаты с тестовой реализацией.
- Реальное время на доске (NFR-4): WebSocket или SSE; гостю — то же или опрос.
- Деньги — целые копейки; снимок цен и модификаторов в позиции заказа (FR-12).
- Аутентификация Mini App — проверка `initData` (HMAC) на каждом запросе (NFR-5).
- Модель данных с `location_id` везде, где это относится к точке (NFR-8).
